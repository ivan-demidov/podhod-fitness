# Подход

Локальный дневник тренировок. В приложении есть планы на 3 и 4 посещения зала, записи подходов, графики, меню и источники. React, TypeScript, Vite, Tailwind CSS, компоненты shadcn/ui и Workbox.

## Пользование

1. Открой опубликованный сайт в Safari. Через «Поделиться» → «На экран „Домой“» добавь ярлык. Если показан переключатель «Открыть как веб‑приложение», оставь его включённым.
2. Открой «Подход» с экрана «Домой» при наличии сети. В «Профиле» можно проверить, готовы ли основные экраны к работе без сети.
3. Импортируй личный файл `podhod-personal.json` через «Загрузить профиль» или «Профиль» → «Импорт». Этот файл передаётся отдельно. Можно ввести данные вручную.
4. На экране «Сегодня» начни тренировку. В дневнике выбери упражнение, введи показатели и сохрани подход. После занятия нажми «Завершить тренировку». Сохранённые подходы можно изменить в истории.
5. Периодически экспортируй копию через «Профиль» → «Экспорт». Очистка данных сайта или удаление установленного приложения может привести к потере данных. Копию можно импортировать на другом устройстве, автоматической синхронизации нет.

Таймер рассчитывает остаток по времени окончания, в том числе после возвращения в приложение. Поддержка фоновых уведомлений и автоматический импорт Fitbit отсутствуют. Для внешних источников требуется сеть.

## Запуск и проверка

Требуется Node.js 22.12+ или 24 LTS.

```bash
npm ci
npm run dev
```

Проверка установленного кэша и офлайн-работы требует рабочей сборки.

```bash
npm run build
npm run preview
```

```bash
npx playwright install chromium webkit
npm run test:e2e
```

Сценарии Playwright используют синтетические данные. `PODHOD_TEST_URL` позволяет тестировать уже запущенную или опубликованную сборку.

## Публикация

На GitHub Pages для папки проекта задаётся путь с завершающим слешем. Для размещения в корне домена оставь настройки по умолчанию.

```bash
PODHOD_BASE=/podhod-fitness/ npm run build
PODHOD_BASE=/podhod-fitness/ npm run preview
```

Опубликуй содержимое `dist` с доступом по HTTPS. Для GitHub Pages есть вариант с веткой `gh-pages`. Добавь в неё содержимое `dist` и пустой файл `.nojekyll`, в разделе Pages выбери публикацию из корня ветки. Личный JSON и файлы Fitbit держи отдельно от репозитория и от развёрнутой сборки.
